# Project instructions

Whenever an agent changes this project, it must also:

- Update `CHANGELOG.md` with a concise description of the changes under the new version and the current date.
- Increase the package version in `package.json` to match the changelog entry. Use a patch increment for fixes and maintenance, a minor increment for new features, and a major increment for breaking changes.
- Group related changes from the same task into one version increment and changelog entry.

These requirements apply to all project changes, including documentation and agent instructions.
